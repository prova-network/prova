# Chain Name Candidates

Criteria: No "coin" in the name. Should evoke storage + intelligence. Memorable, clean, available as .xyz/.io domain.

## Top Picks

### Meridian
- "A great circle of the earth" — connecting points, pathways
- Evokes precision, navigation, infrastructure
- Clean, professional, one word
- meridian.xyz / meridianchain.io

### Axon
- Neural pathway that transmits signals
- Perfect for AI + infrastructure convergence
- Short, punchy, technical
- axon.network / axonchain.xyz

### Veritas
- Latin for "truth" — verified compute, verified storage
- Gravitas, trustworthy, academic credibility
- veritaschain.xyz / veritas.network

### Synapse
- Neural connection point — where AI meets storage
- Very on-brand for AI compute
- Risk: already used by some crypto projects (Synapse Protocol)

### Lattice
- Mathematical structure, crystalline, interlocking
- Evokes both cryptography (lattice-based crypto) and networks
- lattice.network / latticenet.xyz

### Prova
- From "provare" (Latin: to prove, to test)
- Directly references the proof system
- Short, unique, pronounceable
- prova.network / provachain.xyz

### Tome
- A large scholarly book / repository of knowledge
- Storage + AI knowledge = tome
- Very short, memorable
- tome.network

## My recommendation: **Meridian** or **Axon**
- Meridian for gravitas and professionalism
- Axon for technical sharpness and AI-native branding
